# OpenCode 插件集

[English](./README.md) | 中文

OpenCode 插件集合。一个插件一个文件夹,各自独立安装、独立说明。

| 插件 | 说明 |
| --- | --- |
| [opencode-zoom](./opencode-zoom) | 桌面端缩放:记住比例、任意比例设置、步进可调 |

## 加新插件

1. 新建文件夹 `opencode-xxx/`,放进插件本体和它自己的 README;
2. 在上面的表格里加一行;
3. 提交推送:`git add .` → `git commit -m "add opencode-xxx"` → `git push`。
